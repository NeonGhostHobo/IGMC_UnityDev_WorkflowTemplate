# Documentation index

This directory stores durable project knowledge. Keep it compact and grounded in the repository.

- `design/`: intended behavior, architecture, and system contracts.
- `decisions/`: decisions whose rationale should survive the current task.
- `plans/`: active plans that still have unresolved work.

Git history is the archive. Do not maintain duplicate Markdown and JSON versions of the same narrative. Machine-readable contracts belong under `.igmc/`; implementation facts belong near the code; verification evidence belongs with the change or ticket that produced it.
