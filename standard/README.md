# IGMC Workflow Standard

This directory contains the canonical v2 operating standard:

- `repository-operating-standard.md`: Codex-local-first policy;
- `runtime/codex.yml`: GPT-5.6 workload roles and explicit cost boundaries;
- `schemas/`: strict machine contracts;
- `archetypes/`: repository-specific local validation defaults;
- `rules/` and `policies/`: deterministic alignment behavior;
- `assets/managed-assets.json`: core and optional distribution assets.

The standard does not authorize or schedule AI execution. Runtime profiles guide an already-authorized Codex task; they never trigger paid or remote work themselves.
